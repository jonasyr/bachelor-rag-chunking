# Decisions

Binding decisions: `docs/adr/` (one file each; index with status and relations `docs/adr/README.md`). ADRs outrank
`docs/reference` and the exposé. Open decisions: `docs/plan.md`.
- New decision → new ADR with the next number + one row in the index; set back-links in the amended ADR's Status line.
- Never edit an accepted decision (Kontext/Entscheidung/Konsequenzen) — supersede or refine it with a new ADR.
