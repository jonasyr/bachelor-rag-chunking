# RAGAS-Lauf Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A step `src/ragas_eval.py` that scores the 144 answers C1–C3 with four RAGAS metrics (judge `gpt-6-sol`),
stores them once, and two tables in `analyse.py` that report them and their agreement with the rule-based scores.

**Architecture:** `src/ragas_client.py` builds the OpenAI client (with an httpx response hook that records model,
fingerprint and tokens of every API response) and the RAGAS scorer. `src/ragas_eval.py` builds one sample per answer
from the stored files, checks every guard before the first call, scores through an injected scorer, validates, writes
`ragas_scores.csv` all-or-nothing and appends a `ragas` record. `analysis_data` loads the scores (and the unblinded
`answers_question` checks); `report_tables` writes `ragas.tex` and `ragas_agreement.tex`.

**Tech Stack:** Python 3.11+, ragas 0.4.3 (collections API), openai 2.44.0 (`AsyncOpenAI`), httpx event hooks,
pandas, scipy via `src/stats.py`, pytest.

**Spec:** `docs/superpowers/specs/2026-10-21-ragas-design.md`

## Global Constraints

- All parameters only in `src/config.py` (AGENTS.md); judge `gpt-6-sol`, `temperature = 0`, fixed seed,
  `reasoning_effort = "none"`, embeddings `text-embedding-3-large`, `strictness = 3`.
- Four metrics, column names exactly `faithfulness`, `response_relevancy`, `context_precision`, `context_recall`.
- `retrieved_contexts` = the chunk texts of the answer row's `sources`, in that order, one element per chunk.
- Guards before the first API call; all-or-nothing; never overwrite; no K0, no K1.
- A NaN is valid only if the metric itself gives it with a reason; it is stored empty with the reason, counted and
  reported. Anything else (exception after retries, value outside 0–1, NaN without reason, judge model change) writes
  nothing.
- Judge monitoring as ADR 0033: more than one reported model or `system_fingerprint`, or a changed model creation
  time between start and end, writes nothing.
- Tests never call the API (fake scorer, fake `model_created`, `httpx.MockTransport`).
- Conventional Commits, German subjects, no AI attribution; Serena and codebase-memory for code work.

## Review Focus

- Answers file with a row whose `sources` names a chunk missing from the chunk files: refuse before any call.
- A `--set DIR` that resolves to the main catalogue: no pilot exceptions (as `analysis_data.load`), `--repeat`
  refused.
- `ragas_scores.csv` edited after the run, or answers regenerated after it: `analyse.py` refuses (input/output check).
- A question with NaN in one strategy only: means use the other two, W and r drop that question, ρ drops that pair.
- The `ragas_repeat` record must not shadow the `ragas` record (both found separately by `require_run`).

    cost from the recorder's tokens and the config prices
