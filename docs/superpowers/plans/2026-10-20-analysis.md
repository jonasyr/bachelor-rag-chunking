# Analysis and Reporting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `uv run python src/analyse.py` turns the frozen results into the thesis' LaTeX tables, PDF figures, the
confirmatory tests of ADR 0044 and `output/analysis.json`; `--set DIR` does the same for a pilot set.

**Architecture:** Provenance first (run records for `evaluate_retrieval` and `summarise`), then four focused modules:
`stats.py` (pure statistics), `analysis_data.py` (load and check inputs), `report_tables.py` and
`report_figures.py` (render), with `analyse.py` as the thin CLI.

**Tech Stack:** Python 3.12, pandas, numpy, scipy (new, pinned), matplotlib (PDF backend), pytest.

**Spec:** `docs/superpowers/specs/2026-10-20-analysis-design.md`

## Global Constraints

- All parameters in `src/config.py`; tests never call an API; Conventional Commits, German subjects, no AI attribution.
- German labels and decimal comma in every table and figure; tables use `booktabs` rules only; figures black/greys.
- Confirmatory family = R@5 and MRR (main rule) and the answer total: Friedman, Holm over the three omnibus p; pairwise
  Wilcoxon only where the Holm-adjusted omnibus p < `config.ANALYSIS_ALPHA` (0.05), Holm over those pairs. Everything
  else descriptive with effect sizes, no p-values. K0: differences and r, no p-values.
- Cost view: side by side, no combined ratio.
- Same inputs → byte-identical `.tex`, `analysis.json`, `.pdf`.
- Main catalogue: refuse unless frozen (`freeze.require_frozen`) and inputs match the latest run records.

## Review Focus

1. Ties and all-equal columns (most answer scores are 2): Friedman/Wilcoxon must not crash or emit NaN silently; a
   constant metric yields "no test possible" (test `test_constant_metric_is_reported_not_tested`, Task 2).
2. A question missing for one strategy (incomplete grid) must be refused, not silently dropped
   (test `test_incomplete_grid_is_refused`, Task 3).
3. LaTeX special characters in labels or question IDs (`_`, `%`, `&`) are escaped
   (test `test_latex_escapes_special_characters`, Task 4).
4. Negative numbers and rounding with decimal comma (`-0,05`, `1,00`) (test `test_german_number_format`, Task 4).
5. Pilot set without closed-book verdicts or without `data/processed/` files: parts skipped with a note in
   `analysis.json`, no crash (test `test_set_without_optional_inputs_skips_parts`, Task 6).

### Task 2: Configuration, scipy and `src/stats.py`

**Files:**
- Modify: `pyproject.toml`, `uv.lock` (`uv add scipy==<current stable>`), `src/config.py`
- Create: `src/stats.py`
- Test: `tests/test_stats.py`

**Interfaces:**
- Config: `OUTPUT_DIR = ROOT / "output"`, `TABLES_DIR = OUTPUT_DIR / "tables"`, `FIGURES_DIR = OUTPUT_DIR / "figures"`,
  `ANALYSIS_FILE = OUTPUT_DIR / "analysis.json"`, `ANALYSIS_ALPHA = 0.05`,
  `ANALYSIS_PRIMARY = {"recall": "R@5", "reciprocal_rank": "MRR", "total_score": "Gesamtwert"}`,
  `ANALYSIS_RULE = "main"`, `FIGURE_SIZE = (6.0, 3.6)`, `FIGURE_FONT_SIZE = 9`, `FIGURE_DPI = 300`.
- Produces (all pure, inputs = dict strategy → list of per-question values in the same question order):
  - `friedman(values: dict[str, list[float]]) -> dict` → `{"statistic", "p", "kendalls_w", "n", "testable"}`
    (`testable = False` and no p when all values are equal across strategies or n < 2).
  - `wilcoxon_pair(a: list[float], b: list[float]) -> dict` → `{"statistic", "p", "r", "n_nonzero", "testable"}`;
    `zero_method="wilcox"`, two-sided, normal approximation with tie correction; `r = |z| / sqrt(n_nonzero)`.
  - `holm(pvalues: dict[str, float]) -> dict[str, float]` (adjusted, monotone, capped at 1).
  - `confirmatory(metrics: dict[str, dict[str, list[float]]], alpha: float) -> dict` — Friedman per metric, Holm over
    the omnibus p; pairs (C1–C2, C1–C3, C2–C3) only for metrics with adjusted p < alpha, Holm over all those pairs.
  - `effect_sizes(values: dict[str, list[float]]) -> dict` → W and pairwise r without p-values (descriptive metrics).
  - `spearman(x: list[float], y: list[float]) -> dict` → `{"rho", "p", "n"}`.

- [ ] **Step 1: Write failing tests** (values computed by hand or with an independent formula in the test):
  - `test_holm_adjusts_and_keeps_order` — `holm({"a": 0.01, "b": 0.04, "c": 0.03}) == {"a": 0.03, "b": 0.06, "c": 0.06}`.
  - `test_friedman_and_kendalls_w` — 4 questions × 3 strategies with a clear ranking gives `kendalls_w == 1.0`.
  - `test_constant_metric_is_reported_not_tested` — all values 2 → `testable is False`, `"p" not in result`.
  - `test_gating_skips_pairs_when_omnibus_not_significant` — non-significant metric has no `pairs` key.
  - `test_wilcoxon_r_and_zero_differences` — zero differences are dropped (`n_nonzero`), r in [0, 1].
  - `test_spearman_perfect_monotone` — `rho == 1.0`.
- [ ] **Step 2: Run `uv run pytest tests/test_stats.py -q`** — Expected: FAIL (`No module named 'stats'`).
- [ ] **Step 3: Implement `src/stats.py`** with `scipy.stats.friedmanchisquare`, `wilcoxon`, `spearmanr`; Kendall's
  W = χ² / (n (k − 1)).
- [ ] **Step 4: Run tests** — Expected: PASS.
- [ ] **Step 5: Commit** `feat(analysis): Statistik für den Vergleich der Strategien`
