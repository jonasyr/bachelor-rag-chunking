# Entwürfe und Umsetzungspläne (superpowers)

*[Doku-Index](../README.md) · Planung · Verwandt: [Plan](../plan.md#verlauf), [ADRs](../adr/README.md)*

`specs/` (Entwürfe) und `plans/` (Umsetzungspläne) sind datierte Momentaufnahmen, entstanden beim Bau der Pipeline; je
ein Entwurf und ein Plan gehören über Datum und Kurzname zusammen. Sie werden nicht nachgepflegt, auch die
Checkboxen der Pläne nicht. Was gilt, steht im Code, in seiner Dokumentation unter `docs/` und in den ADRs. Jedes Paar
ist in dem Pull Request umgesetzt, den der [Verlauf im Plan](../plan.md#verlauf) für seinen Arbeitsschritt nennt.
