# ADR 0008: Kosten/Effizienz als eigene abhängige Variable

- **Status:** angenommen (D8, verbindlich)
- **Quelle:** Chat; Verhältnis zur Baseline: ergänzt
- **Details:** [Ground-Truth-Leitfaden](../Ground_Truth_Projektleitfaden.md), §12.4

## Kontext

Qualitätsunterschiede sind nur zusammen mit ihrem Aufwand aussagekräftig.

## Entscheidung

Je Strategie werden Chunk-Anzahl, Indexgröße sowie Prompt- und Completion-Tokens erfasst.

## Folgen

Ergebnisse werden als Qualität im Verhältnis zu den Kosten berichtet.
