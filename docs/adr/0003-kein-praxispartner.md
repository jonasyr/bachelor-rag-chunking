# ADR 0003: Kein Praxispartner

- **Status:** angenommen (D3, verbindlich)
- **Quelle:** Chat; Verhältnis zur Baseline: ergänzt
- **Details:** [Ground-Truth-Leitfaden](../Ground_Truth_Projektleitfaden.md), §2

## Kontext

Im Chat bestätigt; die Baseline sah dazu nichts vor.

## Entscheidung

Es wird kein Praxispartner eingebunden (auch nicht die Peano GmbH).

## Folgen

Es werden nur öffentliche Daten genutzt; private Firmendaten liegen außerhalb des Scopes (Leitfaden §3).
